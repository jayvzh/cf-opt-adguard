## 1. 主界面布局（桌面端）

```
┌──────────────────────────────────────────────────────┐
│ Logo         Folder             Sort     PageMode   │
├──────────────┬───────────────────────────────────────┤
│              │                                       │
│              │                                       │
│ Folder Tree  │                                       │
│              │             IMAGE                     │
│              │                                       │
│              │                                       │
│              │                                       │
│              ├───────────────────────────────────────┤
│              │                                       │
│              │  [1][2][3][4][5][6][7][8][9]         │
│              │                                       │
└──────────────┴───────────────────────────────────────┘
```

组成：

- **AppHeader**：Logo、当前文件夹路径、「只看收藏」筛选、SortMenu（排序入口）、PageMode（单页/双页）切换、Settings
- **AppSidebar**：FolderTree 目录树（顶部含虚拟「收藏夹」节点，Sprint 9）
- **Viewer 区**：大图浏览（左上角浮动 ViewerToolbar：Zoom / Fit / 100% / 全屏 / **加载原图** / 图片信息）
- **Filmstrip 区**：底部缩略图条

## 2. 响应式设计

| 设备 | 布局 |
| --- | --- |
| 桌面 | Sidebar + Viewer + Filmstrip |
| 平板 | 隐藏 Sidebar（可展开） |
| 手机 | 全屏 Viewer + 上下 Swipe 翻页 |

## 3. 双页阅读模式（Spread）布局

点击 Header 的 PageMode 切换后，Viewer 进入双页自动拼页（逻辑见 SPREAD_ENGINE.md）：

```
┌──────────────────┬──────────────────┐
│                  │                  │
│     001.jpg      │     002.jpg      │   两张竖图拼成双页
│     (竖图)       │     (竖图)       │   （等高对齐，垂直居中）
│                  │                  │
└──────────────────┴──────────────────┘
┌────────────────────────────────────────┐
│               003.jpg (横图)           │   横图自动独占整屏
└────────────────────────────────────────┘
├────────────────────────────────────────┤
│ [001][002][003][004][005][006]        │   当前帧所有图片同时高亮
└────────────────────────────────────────┘
```

SpreadControls 提供：

- 布局：Single（单页）/ Spread（双页自动拼页）
- 阅读方向：LeftToRight / RightToLeft（日漫右开本）
- WideRatio 调整（横图判定阈值，默认 1.0）
- 封面/封底单页显示开关

> 翻页按"帧"推进：单页帧与双页帧按实际布局混合排列，`←`/`→`/`Space` 一次翻一帧。

## 4. 前端状态设计

### Viewer State（stores/viewer.ts 全局部分）

```
currentFrame   // 当前帧（1~2 张图）
currentFrameIndex
currentImage   // 当前焦点图片（帧内主图）
mode           // single | spread
```

### Viewer Runtime State（useViewer composable，不进 Store）

```
zoom（scale）
panX / panY
rotation
fullscreen
```

### Spread State（stores/spread.ts）

```
pageMode            // single | spread
readOrder           // left_to_right | right_to_left
wideRatio           // 横图判定阈值，默认 1.0
singleFirstPage     // 封面单页
singleLastPage      // 封底单页
frames              // SpreadEngine 计算的帧序列
imageToFrame        // imageIndex → frameIndex 映射
```

## 5. 交互与快捷键

| 按键 | 动作 |
| --- | --- |
| `←` | 上一帧（单页模式即上一张） |
| `→` | 下一帧（单页模式即下一张） |
| `Space` | 下一帧 |
| `F` | 全屏 |
| `0` | Fit（适应窗口） |
| `1` | 100%（原始尺寸） |
| 滚轮 | 缩放（以鼠标位置为中心） |
| 拖拽 | Pan |
| 点击缩略图 | 直达该图所在帧 |
| Filmstrip 滚轮 | 横向滚动缩略图条 |
| `S` | 收藏 / 取消收藏当前图片（双页帧收藏左图） |

> 链路约束：键盘事件由 `useKeyboard.ts` 统一捕获 → 转为 Viewer Action → 操作 ViewerStore，**键盘不直接操作 DOM/组件**。
> 双页模式下翻页以"帧"为单位（一帧 = 1~2 张图，见 SPREAD_ENGINE.md）。

## 6. 关键交互细节

### Filmstrip

- 当前帧包含的所有图片缩略图**高亮边框 + 自动滚动居中**
- 虚拟渲染：视口外不渲染 DOM 节点
- 缩略图懒加载（进入视口才请求 `/api/v1/thumbnail`）

布局规则（**可见数量动态计算，禁止硬编码**）：

- 所有缩略图**显示高度一致**（`THUMB_H`，如 96px），宽度按原始宽高比等比缩放并 clamp（`MIN_W/MAX_W`），竖图不小于最小宽、横图不超过最大宽
- 项与项之间固定间距 `GAP`
- 视口内可见数量 = 容器宽度 ÷（各项宽 + GAP）的累计覆盖，随窗口宽度、缩略图宽窄自动增减；用 **ResizeObserver** 监听容器尺寸变化重算
- 可见区间通过前缀和偏移数组 + 二分查找确定（详见 ARCHITECTURE.md §4.6）

### 图片加载与缓存

- **Viewer 默认加载预览图**（长边 1920px），禁止默认加载原图（原图可能十几 MB）
- "加载原图"按钮：仅当当前显示为预览图时可见；点击后切换加载原图，按钮变为**"原图"常亮标识**，再次点击可切回预览图
- 切换帧时显示 LoadingOverlay（禁止白屏闪烁）
- 只加载当前帧内的图（1~2 张），绝不批量预加载原图/预览图（可预加载相邻 1 帧的预览图）
- Metadata（名称/尺寸/大小/宽高）在打开目录时已随列表返回，无需额外请求
- 所有图片 URL 带版本参数 `v={mtime}{size}`：重访时缩略图/预览图直接命中浏览器缓存（0 网络请求）；原图不自动加载，同一张图重复点击"加载原图"直接命中浏览器缓存；原图被修改后 URL 自动更新（详见 ARCHITECTURE.md §4.3）

### Regex Editor

- 输入即校验，非法 Regex 立即红框提示 `INVALID_REGEX`
- 实时 Preview：文件名 → Group 值 → 排序结果三列展示
- 保存前必须看到 Preview 结果

### 收藏（Sprint 9）

- **查看器**：✕ 号**正下方竖排**心形浮动按钮组（h-7 w-7、默认半透明、hover 增强，不遮挡阅读）；双页帧竖排两个并带 `L` / `R` 小标记；已收藏为柔和红（red-400）实心
- **网格卡片**：右下角心形角标（避开长文件名），hover 才显现，已收藏常亮红；点击不触发打开查看器
- **快捷键**：`S` 收藏/取消当前图（双页帧为左图，无翻页方向分支）
- **入口**：侧栏顶部虚拟「收藏夹」节点（心形 + 数量角标，列表按收藏时间倒序）；顶栏「只看收藏」toggle（目录内筛选，不改 store.images）
- **收藏夹视图**：跨目录混合列表，**强制单页帧化**（仅运行态，不写当前目录 folder_settings）；隐藏排序与阅读入口（避免向虚拟路径发请求/落库）；空态给操作引导
- **门控**：auth enabled 未登录时全部入口隐藏（游客不可见）

## 7. 视觉风格

- 深色为主（图片浏览场景），Tailwind CSS 实现
- 组件交互元素（Modal、下拉菜单等）用 Headless UI，保持样式自定义空间
- EmptyState 组件处理空目录/无图片场景
